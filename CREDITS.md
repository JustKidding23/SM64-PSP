# Credits

SM64 PSP is built on the work of many people. Everyone whose commits are in this
repository's history is also in GitHub's contributor list. This page says who did what,
from the contributor lists of each project on 17 October 2026, most commits first.

## The game

Super Mario 64 is © 1996 Nintendo. This is an unofficial fan project, not made or endorsed
by Nintendo.

## The decompilation: [n64decomp/sm64](https://github.com/n64decomp/sm64)

The game's source code, rebuilt by the n64decomp team so that it compiles to the original
game. Its history was squashed into a few commits, so GitHub only lists
[mountainflaw](https://github.com/mountainflaw), [ahouts](https://github.com/ahouts),
[bramhaag](https://github.com/bramhaag), [matt-kempster](https://github.com/matt-kempster) and
[RevoSucks](https://github.com/RevoSucks). The whole team is credited in that project.

## The PC port: [sm64-port/sm64-port](https://github.com/sm64-port/sm64-port)

The decompilation running as a program on modern systems, with [ariahiro64](https://github.com/ariahiro64), [baosen](https://github.com/baosen), [Jan200101](https://github.com/Jan200101), [mkst](https://github.com/mkst), [nadiaholmquist](https://github.com/nadiaholmquist) and [niansa](https://github.com/niansa).

## The PSP and Dreamcast port: [mrneo240/sm64-port](https://github.com/mrneo240/sm64-port)

[mrneo240](https://github.com/mrneo240) brought the PC port to the PSP and the Dreamcast.
[gyrovorbis/sm64-port](https://github.com/gyrovorbis/sm64-port), which this repository is
forked from, carries it on.
